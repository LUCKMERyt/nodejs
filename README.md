# nodejs

## Команды для установки библиотек Node.js

### Установка всех зависимостей :
```
npm install
```

### Готовые команды для установки библиотек из этого проекта:
```
npm install gulp@^4.0.2 browser-sync@^2.29.3 gulp-autoprefixer@^8.0.0 gulp-clean-css@^4.3.0 gulp-sass@^5.1.0 sass@^1.69.5 --save-dev
```

### Запуск:
```
npm start
npm run build
```
